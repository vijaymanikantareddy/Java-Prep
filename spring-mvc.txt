HTTP Methods:
GET     -> Server Sends some data to Client 
POST    -> Client Sends some data to be saved at Server 
DELETE  -> Client asks to delete some data from Server
PUT     -> Client Sends Some Modified Data (Update) -> Full Update 
PATCH   -> Update -> Small Update like mobileNumber (Partial Update)

Status Codes by Server: 

1xx -> informational 

2xx -> Success
    200 - OK
    201 - Created
    202 - Accepted
    204 - No Content (Deleted)

3xx -> Redirection 

4xx -> Client Side Error 
    400 - Bad Request
    401 - Unauthorized 
    403 - Forbidden (Login Credentials)
    404 - Not Found 
    405 - Method No Allowed (Post)
    409 - Conflict

5xx -> Server Side Error 
    500 - Internal Server Error 
    502 - Bad Gateway
