Like Thread Lifecycle there is Lifecycle for Servlets

There 3 Steps:
1. init -> Initialization
    init()
2. service -> Actual Execution
    doGet()
    doPost()
    doPut()
    doDelete()
3. destroy -> servlet is removed from memory
    shut down your server 
    refresh - redeployed
    destroy()
